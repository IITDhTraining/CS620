
# AST Construction for Python programs
This directory contains the starter materials to create AST for Python programs using the `ast` library of Python.
The contents are:
- `python_parse.py` : program to print the AST of `matmul_cmplx.py` on the terminal.
- `pythonast_to_png.py` : program to convert the AST of `matmul_cmplx.py` to a PNG file for visualization.
- `matmul_cmplx.py` : program to multiply two complex-valued matrices using Numpy library operation. The program contains type annotations for function arguments and assignment expressions, function definitions and calls, Python lists, `import` statement among exercising other Python language grammar rules. 

## Usage
`python3 python_parse.py` prints the AST on the terminal. 
`python3 pythonast_to_png.py` saves the AST in `python_ast.png` file.
